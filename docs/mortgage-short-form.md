# Короткая ипотечная анкета

Кликабельный прототип по [задаче](../tasks/mortgage-short-form/task.md) и [контексту](../tasks/mortgage-short-form/context.md). Основной формат — мобильный экран; на компьютере справа остаётся расчёт. Общие Button, Input, Radio, Checkbox, Icon, Modal и Skeleton используются из UI-kit. Композиция ипотечного сценария и локальные стили полей находятся в `src/pages/MortgagePage.*`, правила и фикстуры — в `src/data/mortgage.ts`.

## Как пройти

1. Откройте `/mortgage` через «Ипотека» в меню, ссылку в футере или «Рассчитать ипотеку» в карточке квартиры. Последний вариант переносит цену и объект через `?listing=1`.
2. В калькуляторе выберите программу, тип жилья, стоимость, взнос и срок. Нажмите «Заполнить заявку на Циане».
3. **О покупке:** срок покупки, наличие объекта, помощь в подборе, доход и кредиты.
4. **Контакты:** ФИО и почта доступны для редактирования, подтверждённый телефон — только для чтения. Отчество не обязательно.
5. **Время звонка:** день и время, необязательное согласие на рекламу. Обязательные условия открываются в диалоге перед отправкой.
6. На экране успеха указаны дата, время, телефон и следующие действия ипотечного партнёра. Можно продолжить поиск жилья.

Маршруты: `/mortgage`, `/mortgage/application?step=1` (шаги 1–3), `/mortgage/success`, `/mortgage/status`. Ссылки на поздние шаги возвращают к первому незаполненному. «Назад», закрытие анкеты и перезагрузка вкладки сохраняют ответы.

## Правила и состояния

- Помощь с подбором показывается при сочетании **семейная ипотека + новостройка**. Это явно выбранная трактовка неоднозначной фразы «только для семейной ипотеки и новостроек» в постановке. Скрытый ответ не включается в результат.
- Сумма платежей по кредитам обязательна только после «Да». Доход и платежи не используются для автоматического решения об одобрении.
- Доступны сегодня и два следующих календарных дня по Москве. Прошедшие часы исключены; если сегодня слотов нет, предлагается выбрать другой день. Сетка обновляется каждые 30 секунд и повторно проверяется при отправке.
- Согласие на рекламу по умолчанию выключено. При уже данном согласии вопрос отсутствует. Согласие и ответы фиксируются только при успешной локальной отправке.
- Ошибки показываются рядом с полями; фокус переходит к первому неверному ответу. Диалоги закрываются по Escape и возвращают фокус на открывшую кнопку.
- Во время отправки поля, переходы назад и кнопка отправки заблокированы. Повторное нажатие не создаёт ещё одну заявку.
- Активная заявка блокирует повторное заполнение, в том числе по прямой ссылке и после перезагрузки. Статусы «выдана», «отменена» и «отказ» разрешают новый сценарий.

Черновик, согласие и результат хранятся в `sessionStorage`, ключ `cian3:mortgage:v1`: в пределах текущей вкладки. Если storage недоступен или повреждён, приложение продолжает работать в памяти. Проверка дублей локальная, между вкладками не синхронизируется.

## Ссылки для ревью

Все примеры доступны в `/patterns`. Параметр `case` создаёт изолированный сценарий и не перезаписывает обычный черновик. В примерах с анкетой нужно пройти шаг «О покупке», чтобы попасть к контактам и отправке.

| Ссылка                                     | Состояние                                                          |
| ------------------------------------------ | ------------------------------------------------------------------ |
| `/mortgage/application?case=empty`         | Пустые ФИО и почта, подтверждённый телефон есть                    |
| `/mortgage/application?case=consented`     | Согласие на рекламу уже дано                                       |
| `/mortgage/application?case=error`         | Первая отправка неуспешна; повтор проходит с сохранёнными ответами |
| `/mortgage/application?case=profile-error` | Ошибка профиля на шаге контактов, повторная загрузка               |
| `/mortgage/application?case=loading`       | Загрузка профиля, затем предзаполненные контакты                   |
| `/mortgage/status?case=active`             | Действующая заявка                                                 |
| `/mortgage/status?case=issued`             | Ипотека выдана, доступна новая заявка                              |
| `/mortgage/status?case=cancelled`          | Предыдущая заявка отменена                                         |
| `/mortgage/status?case=declined`           | По предыдущей заявке отказ                                         |

## Учебные допущения

- Контакты вымышленные. Подключения к профилю, брокеру и банку нет. Отправка имитируется задержкой 800 мс, загрузка профиля — 900 мс.
- Калькулятор ограничен двумя программами и двумя типами жилья. Ставки 6% и 18% служат только для иллюстрации аннуитетного расчёта, не являются текущими предложениями банков или проверкой права на программу. Допустимые диапазоны чисел — технические границы прототипа.
- Из калькулятора переходят регион, стоимость, взнос, срок, тип жилья, программа и ссылка на объект. В локальном результате также хранится сумма кредита. Дополнительный контекст входа задан фикстурой: квартира, работа по найму, без зарплатного проекта, готовность подтвердить доход; конкретный банк не выбран. Эти сведения повторно в анкете не спрашиваются.
- Время звонка: шесть учебных слотов с 09:00 до 19:00, Москва (UTC+3). Это не реальное расписание партнёра.
- Диалоги согласий содержат демонстрационное объяснение, а не юридические документы. Полная банковская анкета, документы, выбор банка, интеграции и смена статуса заявки сервером не входят в прототип.

## Проверка

Поведенческие тесты в `src/pages/mortgage.test.tsx` покрывают вход из карточки, валидацию, условные поля, сохранение, согласия, загрузку и ошибку профиля, сбой отправки и повтор, двойное нажатие, активную заявку, конечные статусы и прямые ссылки. Отдельно проверяются московские даты, смена месяца, прошедшие слоты и повреждённое хранилище.
